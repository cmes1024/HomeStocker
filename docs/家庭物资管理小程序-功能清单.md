# 家庭物资管理小程序功能清单

> 整理依据：`PRD-家庭物资管理小程序.md`（v1.2） + 当前原型 `family-supplies-prototype`
>
> 说明：本清单同时覆盖 **PRD定义功能** 与 **原型已呈现功能/页面能力**，用于产品、设计、研发统一对齐范围，尽量避免遗漏。

---

## 1. 功能清单总览

| 一级模块 | 二级模块 |
|------|------|
| 新手引导与进入逻辑 | 首次引导、创建家庭、加入家庭、进入首页逻辑、授权与隐私说明 |
| 家庭管理 | 创建家庭、加入家庭、切换家庭、家庭列表管理、家庭基础设置、家庭邀请码、退出/解散家庭、家庭提醒总开关 |
| 角色与权限 | 创建者、管理员、普通成员、只读成员 |
| 首页总览 | 当前家庭概览、家庭快捷切换、提醒看板、快捷入口、临期物资预览、最近操作 |
| 物资管理 | 添加物资、OCR/扫码/语音补充、物资列表、筛选搜索排序、卡片/表格、详情、编辑、删除、库存快调 |
| 存放位置管理 | 预设位置、自定义位置、位置视图 |
| 保质期与提醒 | 到期提醒、过期标记、临期筛选、提醒开关、提醒总开关、保质期日历 |
| 分类管理 | 预设分类、自定义分类、分类统计 |
| AI辅助录入 | OCR拍照录入、扫码录入、语音录入、手动确认、批量识别 |
| 采购管理 | 采购清单、智能建议、消耗统计 |
| 通用能力 | 底部导航、返回、数据隔离、异常提示、离线查看、兼容性与性能要求 |

## 2. 详细功能清单

### 2.1 新手引导与进入逻辑

| 功能点 | 说明 | 来源 | 原型体现 |
|------|------|------|------|
| 首次引导仅在无家庭时展示 | 仅在首次打开且未创建/未加入任何家庭时展示引导页 | PRD | `引导页` 文案已体现 |
| 已有家庭直接进入首页 | 用户已有家庭记录时，跳过引导直接进入首页 | PRD | 进入逻辑已在引导页说明文案中体现 |
| 创建家庭入口 | 新用户从引导页创建第一个家庭 | PRD + 原型 | `引导页` `cta-create-family` |
| 加入家庭入口 | 新用户通过邀请码加入已有家庭 | PRD + 原型 | `引导页` `cta-join-family` |
| 创建/加入后进入首页 | 创建或加入家庭后，进入默认家庭首页 | PRD + 原型 | `.design` 页面跳转已登记 |
| 引导价值说明 | 说明产品价值：避免重复采购、临期提醒、家庭协同 | 原型 | `引导页` 三个价值卡片 |

## 5. 建议使用方式

这份清单建议作为以下工作的统一基线：

1. 产品排期时，按“当前原型已体现的高优先级功能”优先进入开发范围
2. 详细设计或补原型时，逐项核对“PRD已定义但原型未完整展开的功能”
3. 研发拆任务时，按模块拆为：家庭管理、首页、物资管理、AI录入、提醒系统、采购管理、通用能力
4. 测试设计用例时，按本清单逐项建立正向、异常、权限、跨家庭隔离用例
