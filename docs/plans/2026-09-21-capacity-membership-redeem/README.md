## 一句话

免费档硬上限：**1 个家庭 / 2 名成员 / 50 件物资**；内测兑换码核销到**当前家庭**后升为加强版（三项都不限），该家全员共享；站内只展示「内测兑换」，不引导站外购买。AI 继续 BYOK，**本刀不卖 AI**。

## 核心原则

1. **控云开发，不控模型**：门控对准会放大读写的容量（家庭数、成员数、物资件数）。
2. **按家庭卖、全员共享**：物资/人数以 `familyId` 订阅为准；「一人可进几家」看该用户是否已有任一家有效加强版。
3. **闸门只在写路径**：读列表不查会员；避免「查会员比省下的读写还贵」。
4. **配置表驱动**：套餐限额、产品天数集中在一处，便于内测调参与后续加档。
5. **件数用计数器，不每次全表 count**：门控热路径只做「读订阅 + 读/改计数」级开销；人数用已有 `families.memberCount`。
