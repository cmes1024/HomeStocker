# 家庭容量会员 — 落地步骤

## 阶段总览

| 阶段 | 目标 | 预估 | 成功信号 |
|------|------|------|----------|
| **P0 · 计数 + 配置** | `itemCount`；entitlements 含三项 limit | 已完成大半 | free=1/2/50；capacity_std=不限 |

### 手测清单

- [ ] 新用户可建 **1** 家；再建第二家 → `FAMILY_LIMIT_REACHED`
- [ ] 免费家最多 **2** 人；第三人 join → `MEMBER_LIMIT_REACHED`
- [ ] 可创建至 50 件；第 51 件 → `ITEM_LIMIT_REACHED`
- [ ] 兑 `capacity_90d` 后：可再加家、加人、加物资（不限）
- [ ] 未过期再兑：到期日按剩余叠加
- [ ] 过期回落 free：已有超额不删不踢，但不可再增家/人/物
- [ ] 切换家庭：权益不在新家（除非新家也有订阅）
- [ ] 解散清订阅
- [ ] 列表/搜索无 entitlement 风暴
- [ ] `createMany` 超剩余整批失败
- [ ] AI extract 不因无会员被拦（仍可因物资上限失败）
