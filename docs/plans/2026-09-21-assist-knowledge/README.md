# 助手知识库（渐进读取）

> 日期：2026-09-21  
> 状态：实现中  
> 范围：`ai.act` 产品/容量类问答；先代码包，schema 对齐未来 `aiKnowledge` 集合

## 原则

1. **禁止一股脑塞进 system prompt**：正文不进默认上下文。
2. **渐进式**：prompt 只注入短目录（`topicId` + 一行摘要）；模型按需 `knowledge.get` 取**一个** topic。
3. **可改扩**：topic 文件独立；迁库时同字段读 DB，匹配/工具不变。
4. **真相**：限额数字以 `entitlements` + 当前家订阅为准，FAQ 文案与实时用量分开拼。

## Schema（代码包 / 未来集合共用）

| 字段 | 说明 |
|------|------|
| `topicId` | 如 `capacity` |
| `version` | 整数；改文案 bump |
| `enabled` | bool |
| `title` | 短标题 |
| `summary` | 一行，进目录 |
| `triggers` | 可选；预留检索，本刀不靠关键词强灌正文 |
| `body` | 完整说明（仅 get 时返回） |

## 运行时

- `{{KNOWLEDGE_INDEX}}`：启用 topic 的目录；无则「无」
- 能力：`knowledge.get`，参数 `topicId`
- 单轮建议只取 1～2 个 topic；工具侧硬顶 3
- `capacity` get 时附加本家权益摘要（active / 件数·人数）

## 不做

- 关键词自动把全文打进 prompt  
- RAG / 向量库  
- 站内购买引导、报价、站外电商/闲鱼等渠道名  

## 获取取向口径（capacity，合规）

面向「怎么买 / 多少钱 / 怎么开通」类问题，知识正文与助手必须遵守：

1. **只谈内测兑换码**，不谈「购买」「下单」「微信支付」。  
2. **不报价格**，不提任何站外平台或私下转账。  
3. **有码** → 引导家庭页 VIP 兑换；**无码** → 若云函数 `ai` 配置了 `CAPACITY_ADMIN_WECHAT`，引导添加该微信号申请内测；未配置则只说等官方通知、禁止编造微信号。禁止报价与站外平台。  
4. 被追问闲鱼/淘宝等 → 明确不介绍站外交易，回到「申请内测 + 家庭页兑换」。
