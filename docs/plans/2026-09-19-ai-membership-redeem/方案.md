# AI 会员兑换 — 技术方案

## 1. 结论

| 项 | 约定 |
|----|------|
| 支付 | 站外（闲鱼）售码；小程序内兑换。无微信内购 |
| 权益主体 | **家庭**（`familyId`），非个人 |
| 谁能用 | 该家任意成员，有效期内可调 AI |
| 模型钱 | 仍 `familyAiKeys` BYOK；会员卖的是「家庭 AI 使用权」 |
| 闸门 | 云函数 `ai.extract` / `transcribe` / `act`；密钥 CRUD、`attachMedia`、`listKeys` 不闸 |
| 换绑 | 第一版不做 |

## 2. 生命周期

| 事件 | 行为 |
|------|------|
| 兑换 | 须已加入家庭；码绑到 `currentFamilyId`；`expiresAt` = max(现有到期, now) + 产品天数 |
| 切换家庭 | 权益留在原家 |
| 离开 | 个人带不走；家仍有效则留守成员继续用 |
| 解散 | 删该家 `familySubscriptions`；已用码保留审计，不回收 |
| 一码 | 单次核销；`unused` / `used` / `revoked` |
| 一家 | `_id = familyId` 一条订阅；续兑延长 `expiresAt` |

## 3. 集合

### `redeemCodes`

| 字段 | 说明 |
|------|------|
| `_id` | `codeHash`（SHA-256 hex of 规范化明文） |
| `product` | 如 `ai_season_90d` |
| `days` | 90 |
| `status` | `unused` \| `used` \| `revoked` |
| `usedByFamilyId` / `usedByOpenid` / `usedAt` | 核销时写 |
| `createdAt` | 发码时 |
| `note` | 可选运营备注 |

明文只在发码接口返回一次，库内只存哈希。

### `familySubscriptions`

| 字段 | 说明 |
|------|------|
| `_id` | `familyId` |
| `familyId` | 同 `_id` |
| `product` | 最近一次产品 id |
| `source` | 恒 `redeem`（预留日后 `wechat_pay`） |
| `expiresAt` | ms |
| `lastRedeemCodeId` | 最近码 `_id` |
| `updatedAt` / `createdAt` | |

客户端写 deny。

## 4. 云函数 `ai`

| action | 说明 |
|--------|------|
| `getSubscription` | 当前家订阅快照 `{ active, expiresAt, product }` |
| `redeem` | 入参 `code`；核销 + 续期 |
| `issueCodes` | **仅** `OPENID === process.env.ADMIN_OPENID`；入参 `count`/`product`/`note`；返回明文码列表 |
| `extract` / `transcribe` / `act` | 开头 `requireAiSubscription`；失败 `SUBSCRIPTION_REQUIRED` |

核销防双兑：`where({ _id, status: 'unused' }).update(...)`，`stats.updated === 0` 则拒绝。

产品表（代码常量）：

```
ai_season_90d → days: 90
```

## 5. `family` 解散

`cleanupFamilyAiArtifacts` 增删 `familySubscriptions`（按 `familyId`）。

## 6. UI

家庭页在「AI配置」旁加一行「AI 会员」：展示到期日或「未开通」；点开 `PromptDialog` 输入兑换码；成功 Toast 到期日并刷新。

助手 / 录入遇 `SUBSCRIPTION_REQUIRED` 时 Toast 引导去家庭页兑换（文案在 `copy`）。

## 7. 明确不做

微信虚拟支付、自动续费、个人席位、换绑、免费日额度计量、平台托管 Key、物资/空间数量上限。
