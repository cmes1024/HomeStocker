# A 波设计：物品详情、氛围清理、性能

> 日期：2026-09-10  
> 状态：已确认  
> 路线总览：`2026-09-10-next-abcd-roadmap.md`  
> OpenSpec：`openspec/changes/item-detail-atmosphere-perf/`

---

## 目标

把清单从「点进就改」改成「先看后改」，并按顺序做性能加固。

> 注：原「氛围图云存储清理」已随产品演进废弃——家庭氛围仅保留命名主题（`background: { type: 'theme', value }`），不再支持自定义图片。

## 决策摘要

| 项 | 决策 |
|----|------|
| 清单点击 | 仅进入详情页 |
| 清单长按删除 | **取消** |
| 编辑 / 删除 | 仅在详情页入口 |
| 家庭氛围 | 命名主题三色；无纯色 / 自定义图 |
| 性能顺序 | 分包+异步 → 轻量优化 → Workers |

## 1. 物品详情

- 新页：`pages/items/detail`（建议进分包，见性能）。  
- 展示：名称、数量+单位、空间、位置、备注；为 B 波字段预留展示位但不实现。  
- 操作：编辑 → 现有 `pages/items/edit`；删除 → 确认后走 `item.remove`，成功返回清单。  
- 清单卡片：简要信息（名称、数量、可选位置一行）；`bind:tap` → 详情；去掉 `longpress` 删除。

## 2. 家庭氛围（主题）

- 写路径：`family.updateBackground`，仅接受 `{ type: 'theme', value: themeId }`。  
- 客户端按 `themeId` 解析主色 / 副色 / 阴影色，经 AppShell 注入 CSS 变量。  
- 不做：自定义上传图、纯色预设、氛围图 `deleteFile`。

## 3. 性能（顺序执行）

### 3.1 分包 + 异步

- 主包：onboarding、清单、家庭设置、编辑（高频写路径可留主包或按体积再定）。  
- 分包候选：`pages/spaces/*`、`pages/items/detail`；按需 `wx.navigateTo`。  
- 非关键请求可延后（如空间列表不在首屏预拉）。

### 3.2 轻量优化

- 减少不必要 `setData`；清单返回静默刷新（已有模式可复用）。  
- 避免重复全量拉主题。

### 3.3 Workers

- 在 3.1/3.2 之后：将可纯计算逻辑（如列表派生、后续过期计算）迁 `workers`；本波末尾，不强行塞复杂业务。

## 非目标（A）

标签、保质期、订阅消息、首页即将过期、家庭消息流、为「新」而新的交互堆砌。

## 验收要点

- [ ] 清单点击进详情；无长按删除  
- [ ] 详情可编辑、可删除并回清单  
- [ ] 家庭氛围仅可选命名主题；切换后全站主题色与径向渐变一致  
- [ ] 空间与详情等进入分包；主包体积下降可感知  
- [ ] 轻量优化有落地项；Workers 至少有一处可运行的接入或明确延期记录
