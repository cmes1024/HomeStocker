# 家庭管家素养课表

> 日期：2026-09-23  
> 状态：**实施中**  
> OpenSpec：[`openspec/changes/ai-assist-curriculum/`](../../../openspec/changes/ai-assist-curriculum/)

把管家从「会写库的对话壳」收到「合格办事员 + 产品导游」。练的是产品素养（场景、产品、职能、能力），不是微调模型。V3 主路径不动。

**办砸了先读 [`迭代指南.md`](./迭代指南.md)：** 各模块职责 + 按症状排查。禁止往 prompt/hint 加「说 xxx 就做 xxx」。

## 层归属

| 层 | 只住什么 | 不是什么 |
|----|----------|----------|
| prompt | 人格、通道、业务边界 | 场景口诀、话术→工具 |
| knowledge | 产品 / 职能 / 台账概念 / 容量口径 | 办事步骤 |
| capability hint | 接口说明书（是什么、参数、硬限制） | 「用户说什么时该用」 |
| 代码 | 身份、白名单、确认、消息轮次、写闸门 | 意图路由 |

课表是人看的考试，不进运行时，也不指示「办砸了就往该层加口诀」。

## 三阶段与预期

| 阶段 | 做完时的样子 | 怎样算过 |
|------|--------------|----------|
| 1 课表 | 核心/扩展场景都有层归属 | 办砸了能指出改哪一层；本阶段不改运行时代码 |
| 2 知识 | 目录有 `product` / `role` / `ledger` / `capacity`；prompt 不再整篇内联 | 问职能/概念/限额会 `knowledge.get`；各加 1 → 撤销不回退 |
| 3 hint | 启用接口 hint 含禁用句 | 「各加」走 update 不走 create；打开标签管理走 `page.get` |

详细场景见 [`课表.md`](./课表.md)。手测步骤见 [`验收.md`](./验收.md)。  
查阅外文书时用 [`指南对照.md`](./指南对照.md)：办砸时指南会怂恿改哪、课表要求改哪。

## 高度（三阶段后）

合格的台账办事员 + 产品导游：核心活办稳、能解释产品和自己、能指路、守硬边界。  
不到：更会推理、记住这家习惯、新开放写接口、自动评测满分。
