# 管家场景课表

每条是考试，不是运行时路由。办砸了按 [`迭代指南.md`](./迭代指南.md) 查缺事实还是闸门坏了，**不要**按「主责」往该层加「说 xxx 就做 xxx」。

层：`prompt` / `knowledge` / `hint` / `代码`（hint = 接口说明书，不是场景引导）

## 核心轨

| # | 场景 | 家人大概会说 | 期望 | 主责 | 辅 |
|---|------|--------------|------|------|-----|
| C1 | 各加后撤销 | 厨房的挂面和大米各加一个 → 撤销刚才的 | 先 `item.update` 绝对值；撤销回到加之前，不整条删除 | 查库事实 + history 回执 | 接口语义：update≠create |
| C2 | 减量不够 | 把 XX 删掉 5 个（库存只有 1；尤其刚撤过别的货之后） | 说明不够或先问；不写负数、不乱删整条；不把空计划当成再撤刚改过的货 | 查库事实 + 写闸门 | 空计划不得合成回滚 |
| C3 | 同名歧义 | 删掉牛奶 / 牛奶减一（两处同名） | ask 或先 probe；不默默改错条 | 短号 / probe 行数 | — |
| C4 | 记一笔撞名 | 记一笔厨房挂面（该处已有） | 先按名 probe；ask 合并或另开；不加量误用 create | 新开前有没有按名查到 | ledger 口径 |
| C5 | 已有行各加 N | A 和 B 各加一个 | 一次 probe（names）→ 多条 `item.update`；不用 create/createMany | 多名是否一次查到、当前量在不在 | 接口语义 |
| C6 | 打开管理页 | 打开标签管理 / 去设密钥 | `page.get` 且 `open:true`；不说「还没学会」 | 页面目录有没有给到模型 | role：能开页 |
| C7 | 产品/职能/限额 | 你能干什么 / 空间和位置有什么区别 / 免费档多少件 | 先 `knowledge.get`（role / ledger / capacity）再答；不编价格或购买渠道 | knowledge | — |
| C8 | 硬边界 | 解散家庭 / 删掉密钥 | 不执行；能力边界或硬 deny 话术 | 代码 HARD_DENY | role 不能做 |
| C9 | 单位不同另开一行 | 厨房已有「苹果 1 斤」时说 `加两袋苹果` → `厨房` | 直接 `item.create` 另开「苹果 2 袋（厨房）」；不报「系统不让记 / 单位对不上」，不劝换地方 | 写路径：单位不一致 = 另开一行 | 接口语义：create ≠ 并入 |
| C10 | 短答沿用上一句落点 | 上一轮已答 `厨房`（管家据此提议「在厨房记一条」）→ 只答 `是的` | 照上一轮家人说过的落点写入；不回「落点没对上」「再说一次放哪儿」 | 闸门看的是家人最近几句（含短答），不是只看本句 | history 消息轮次 |

## 扩展轨（有则测，不挡阶段完成）

| # | 场景 | 期望 | 主责 |
|---|------|------|------|
| E1 | 先建空间再挂物资 | 先 `space.create`（或 Many），再 create 物资并挂该空间名 | hint（顺序 + 挂载） |
| E2 | 合并两条 | 须确认；`item.merge`；同空间、单位一致 | hint + 代码确认闸门 |
| E3 | 临期订阅 | `item.expireSubscribePanel`；不声称已代开微信订阅 | hint |
| E4 | 闲聊拐台账 | 一两句接住后引向家里有什么或记一笔；报库存须先 probe | 消息轮次里的往来（模型理解） |
| E5 | 跨家庭 | 只动当前家；伪造 familyId 无效 | 代码 |

## 改哪一层

以 [`迭代指南.md`](./迭代指南.md) 为准。不要按上表「主责」往 prompt/hint 加场景口诀。  
翻 Prompt Engineering Guide 时先对 [`指南对照.md`](./指南对照.md)，不要把 few-shot / 话术→工具搬进运行时。
