## 一句话

基础台账（建家 / 加人 / 记物资 / 空间 / 标签 / 过期提醒 / 消息流）**永远免费**；
AI 拍照录入（V1）做免费额度节流、AI 自然语言助手（V2）做会员专享、主题与容量做差异化，
按 **家庭** 维度卖会员（一户一单，全员共享），默认套餐 ¥12/月 或 ¥98/年。

## 核心原则（设计底线）

1. **免费版够用**：手动台账 + 少量 AI 体验（V1 每日 5 次 / 人），保证口碑传播不被付费墙打断。
2. **按家庭卖、不按人卖**：与产品定位一致，避免同一家庭多人重复购买的校验复杂度。
3. **门控只在云函数**：前端只做 UI 灰化 / 引导跳转，不把额度 / 套餐真相放客户端。
4. **BYOK 兼容**：自带 DeepSeek Key 的家庭在任何套餐下都能走自己的 Key，不消耗官方额度，也不产生模型成本。
5. **成本熔断优先于收入**：`gatekeeper` 里硬编码单家庭日调用上限 + 单家庭月成本熔断，避免被刷爆。
