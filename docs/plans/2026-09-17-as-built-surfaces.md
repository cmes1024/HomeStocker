## 1. 家庭页（钥匙 + 工具格）

路径：`pages/family/index`

| 块 | 行为 |
|----|------|
| 钥匙卡 | 展示当前家邀请码；复制；可分享给微信好友。文案是「把门钥匙给家人」，不是管理后台 |
| 临期提醒 | 钥匙卡内按钮（文案如「临期提醒·上午9点」/「临期提醒关闭」）；点开弹框可改总开关、提醒时间线（单选提前 0/1/3/7/14 天）、发送时间（时:分），一次性保存走 `family.updateExpireReminder` |
| 工具格 | 家庭空间 / 物品标签 / 消息中心 / 家庭氛围（命名主题） |
| AI 额度 | 单独一行进 `packageAi/keys` |
| 我加入的家庭 | 列表切换；创建另一家；邀请码再加入 |
| 退出 | 所有者解散清数据；成员离开；若还有别的 membership 则切过去 |

成员列表、昵称头像、角色权限：**没有**，不是这一版漏画，是第一阶段还没做用户体系。

主题写入见 `docs/plans/2026-09-15-family-theme-system.md`。预设 17 套（默认 `orange` 暖黄橙，另有红/蓝及抹茶、奶油、香芋等）。家庭氛围弹层一行最多 3 个，列表可滚。不再支持纯色、CSS 渐变字符串、自定义氛围图。

## 2. 物资清单首页（货架）

路径：`pages/items/index`

对齐「存哪儿」式浏览，不是旧 PRD 的仪表盘首页。

- 顶栏家庭名、成员/物品/空间计数、「进入家庭」、添加
- 临期横幅最多一条（`listExpiring` limit 1），点进消息中心
- 面板标题 + **按空间筛选**（底栏 chip）
- 货架 tile：名称、数量/单位、过期角标；点击进详情分包
- 右下角 **AI** 浮窗进采集分包
- 导航左侧搜索样式是**占位**：没有输入、没有跳转。`item.search` 云函数仍在，给后续搜索 UI / Agent 用

标签筛：接口支持 `tagId`，首页没有入口。

## 3. 空间口袋

路径：`packageBrowse/pockets/index`（browse 分包已注册）

按空间把最近放入的物品收成「口袋」，打开后看位置文案。读的仍是 `items`，不是第二套库存。

**现状：没有任何产品页 `navigateTo` 到这里。** 空间列表点进去是 `spaces/detail`。缓存方案已把口袋标成「无入口」。本页保留为已实现实验面，补入口前不要当主路径验收。
