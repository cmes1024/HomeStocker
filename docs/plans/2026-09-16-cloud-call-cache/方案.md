# 领域读缓存方案

> 目录：`docs/plans/2026-09-16-cloud-call-cache/`  
> 场景清单：[`场景.md`](./场景.md)（S 号以那份为准）  
> 状态：已落地（调用层）。行为合同：`openspec/specs/cloud-read-cache/spec.md`。  
> **2026-10 修订（Java 后端）：** 云函数额度目标已退役；保留 L1 跳页体感与写作废 / cursor，改为短 TTL，家庭页每次 `onShow` 走 `load`。

## 1. 目标

（历史）减少小程序对云开发**函数调用次数**的消耗。  
（现状）Java HTTP 无云函数额度约束；L1 仍用于**同会话短时跳页复用**与防连点双请求，并以 TTL 限制前台驻留脏读。

页面继续 `onShow` 里拉数、继续 `callItem('search')` 这类写法；TTL 内同样的读在调用层直接返回，不出网。

不把「要不要刷新」散落成每页 `forceRefresh`。不引入 `wx.storage` 持久化读结果、实时监听。

## 2. 耦合边界

```
页面 / db.js                    默认不调 invalidate、不判断命中、不探水位
        │                       （家庭页 onShow 每次 load 仍只调 callFamily）
        ▼
  utils/cloud.js                唯一入口：读缓存 / 写后作废 / 回前台探水位 / TTL
        │
  utils/queryCache.js           内存表 + expiresAt + 同 key 并发合并
        │
        ▼
  Java HTTP（utils/javaApi）    未命中 / 过期才出去
```

业务代码看起来仍在请求。省的是**出网次数**，不是 `await` 本身。

### 核心文件

| 文件 | 职责 |
|------|------|
| `miniprogram/utils/queryCache.js` | 内存缓存、key、TTL、并发 inflight |
| `miniprogram/utils/cloud.js` | 读走缓存、写成功按策略作废、回前台探 cursor、按域 TTL |
| `miniprogram/utils/session.js` | `getMyFamily` 走 `callFamily` |
| `miniprogram/app.js` | `onHide` / `onShow` 只打「是否从后台回来」旗标 |
| `miniprogram/pages/family/index.js` | `onShow` 每次 `load()`（经调用层，可命中 TTL） |

新增领域读/写 action 时：只改 `cloud.js` 里的策略表与 TTL 归属。

### 明确不保证（与 cursor 盲区）

- 家人改空间名/标签名/主题：无 activity 时 cursor 发现不了；依赖结构域 TTL（45s）或本机写作废
- 物资写成功但活动插入失败时的水位漏洞（接受）
- 不做 WebSocket / 实时推送；不删整层 `queryCache`

## 3. 行为（四层）

```
自己增删改 ──► 写成功后按模块作废 ──► 下一屏 onShow 仍调原接口，未命中则出网

仅跳页/返回（TTL 内）──► 同样的读 key 命中 ──► 0 次出网

TTL 过期 ──► 视为未命中 ──► 出网并写入新过期时间

App 从后台回来 ──► 旗标 + 第一次物资域读时打 activity.cursor（全进程合并成 1 次）
                 ├ 水位没变：物资缓存保留（仍受 TTL 约束）
                 └ 水位变了：只作废物资域，这次读出网
```

空间/标签没有 activities。本机改空间/标签走「写成功作废」；家人改名主要靠结构域 TTL，回前台 cursor **不保证**发现。

临期：`listExpiring` / `item.home` / `bootstrap.home` 的缓存 key 带上海时区当天日期。过零点 key 变，自然未命中。

## 4. 缓存键、TTL 与内存

- 作用域：进程内存。冷启动为空。切家/离开时整表清空。
- key：`familyId | 模块名 | action | 稳定序列化(业务参数)`  
  `familyId` 取 `globalData.familyId`（或 `family._id`）。尚无家庭时**不缓存**，直接出网。
- 参数：去掉 `action`；对象 key 排序后序列化。`undefined` 与缺省视为相同。
- `listExpiring` / `home` / `bootstrap.home` 额外拼上海 `today=YYYY-MM-DD`。
- `tag.ensureDefaults` 与 `tag.list` **共用** `tag | list | {}`。
- 失败不入缓存。同 key 并发只打一次出网。
- **短 TTL（Java 后）：**
  - **物资域 15s**：`item.*` 读、`activity.list`、`bootstrap.home`、`space.listItemsBySpace|listPockets|detail`
  - **结构/家庭域 45s**：`family.*` 读、`space.list|listLocations`、`tag.list`
  - 过期视为 miss 并删除条目；写作废 / cursor / 切家仍立即清空相关键

## 5. 策略表（唯一业务知识）

写在 `cloud.js`。按**模块 + action**，不按页面、不按字段。

### 读（可缓存）

| 模块 | action | TTL |
|------|--------|-----|
| family | `getMyFamily` `listMyFamilies` `listMembers` `page` | 结构 45s |
| item | `get` `detail` `editForm` `search` `list` `count` `listExpiring` `home` | 物资 15s |
| space | `list` `listLocations` | 结构 45s |
| space | `listItemsBySpace` `listPockets` `detail` | 物资 15s |
| tag | `list` `ensureDefaults` | 结构 45s（共享 list 键） |
| activity | `list` | 物资 15s |
| activity | `cursor` | **不缓存结果**；探针 + inflight 合并 |
| bootstrap | `home` | 物资 15s |

未登记的读：默认出网、不缓存（安全）。

### 写（出网 + 作废）

作废用粗粒度，避免缓存层理解字段：

| 写成功 | 作废 |
|--------|------|
| `item`：`create` `createMany` `update` `remove` `removeMany` `merge` | 物资域（item + activity + bootstrap + 含物资的 space 读） |
| `space`：一切非上表读 | 全部 `space` 读 + `bootstrap` |
| `tag`：一切非 `list`/`ensureDefaults` | 全部 `tag` 读 |
| `family`：`create` `join` `leave` `switchFamily` | **整表清空** |
| `family`：`updateBackground` `updateExpireReminder` `updateName` `updateProfile` `redeem` | family + bootstrap（profile/redeem 另作废 activity） |
| `family`：`recordSubscribeExpire` | 不作废列表 |

未登记的写：默认 **整表清空**（宁可多重打，不要脏读）。

## 6. 回前台探针

`app.js` 只维护旗标，不拉业务数据：

- 冷启动第一次 `onShow`：不探（缓存本空，页面会正常拉）。
- `onHide`：记「曾经进过后台」。
- 之后的 `onShow`：置 `needsItemRevalidate = true`。

`cloud.js` 在处理物资域读之前：

1. 若无 `needsItemRevalidate`，按普通缓存（含 TTL）走。
2. 若有：全进程只发一次 `activity.cursor`；与本地记住的水位比较（bootstrap.home 则直接 drop 物资域，避免重复 cursor）。
3. 相同或 cursor 失败：**保缓存**（失败开放；仍受 TTL 约束）。
4. 不同：作废物资域，再让本次读取出网。
5. 清掉旗标；记下新水位。

## 7. 按场景的决策（节选）

| 场景 | 决策 |
|------|------|
| 跳页 / 返回（TTL 内） | 命中，0 次出网 |
| 前台驻留超过物资 TTL 再进清单 | miss，出网 |
| 家庭 Tab 反复进入 | 每次 `load`；45s 内可命中 `family.page` |
| 本机写物资 | 立即作废物资域 |
| 家人改物资 + 回前台 | cursor 变则作废 |
| 家人改物资 + 一直前台 | 最多等到物资 TTL |
| 家人改空间/标签名 | 结构 TTL 或本机相关写；cursor 不保证 |
| 过零点临期 | key 含日期 |

## 8. 验收要点

- 本机增删改物资：即时反映（写作废）
- 15s 内清单 ↔ 详情：可命中
- 前台停留 >15s 后再进清单/消息：重新拉数
- 家庭 Tab：每次走 `load`（TTL 内可能仍命中）
- 回前台 + 家人有物资活动：cursor 作废物资域
- 切家：整表清空
