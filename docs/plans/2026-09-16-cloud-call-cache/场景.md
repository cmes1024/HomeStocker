# 云函数读场景清单

> 目录：`docs/plans/2026-09-16-cloud-call-cache/`  
> 本文只盘「现在会打哪些读、什么时候打、数据有没有可能已经变了」。  
> 方案（已确认）：[`方案.md`](./方案.md)  
> 次数是一次触发里的云函数调用数（`wx.cloud.callFunction`），不含数据库直读（客户端对业务集合是 deny 的）。

## 怎么读这份清单

- **Sxxx**：原子场景，后面方案按编号对齐。
- **触发**：用户动作或系统生命周期，不是页面名。
- **可能已变**：这次触发后，屏幕上的数据有没有理由和上次不一样。
- **变更来源**：`自己` / `家人` / `时间` / `无`。`无` 表示只是页面又 show 了一次，物资本体通常没动。
- 产品页以 `app.json` 为准。`pages/chat`、`pages/demo`、`pages/index` 不在启动路径里，不列入。
- 口袋页 `packageBrowse/pockets` 已注册，但目前没有其它页跳过去；仍列出，标为「无入口」。

## 生命周期（几乎所有「狂刷」都来自这里）

微信会在这些时候调当前页 `onShow`（从后台回前台时，当前页也会再 `onShow`）：

| 事件 | 典型结果 |
|------|----------|
| 冷启动 | 先打开 `pages/onboarding` |
| `navigateTo` | 新页 `onLoad` + `onShow`；旧页 `onHide`，实例还在 |
| `navigateBack` | 旧页再次 `onShow` |
| 切到其它微信页再回来 | `App.onShow` + 当前页 `onShow` |
| 没有下拉刷新 | 全项目无 `onPullDownRefresh` |

## A. 页面出现时的读（当前实现）

### 会话 / 家庭

| ID | 触发 | 页面 | 当前调用 | 约次数 | 可能已变 | 变更来源 | 现状 |
|----|------|------|----------|--------|----------|----------|------|
| S101 | 冷启动，无家庭缓存 | onboarding `onShow` | `family.getMyFamily`（`ensureSession`） | 1 | 要知道有没有家 | 自己（上次会话） | onboarding **先 `setAppFamily(null)`**，等于每次进这页都强制打会话 |
| S102 | 冷启动，已有家庭 | onboarding `onShow` → `reLaunch` 首页 | 同上，成功后进首页 | 1 + 首页整包 | 同 S101 | 同 S101 | 有家也会先经过 onboarding |
| S103 | 打开物资首页 | items `onShow` | `ensureSession`；若 `globalData.family` 已有则**不打** | 0 或 1 | 家庭主题/人数可能变 | 家人也可改主题 | 会话是目前唯一跨页内存缓存 |
| S104 | 打开家庭页（本页还没有 `data.family`） | family `onShow` → `load` | `getMyFamily` + `listMyFamilies` | 2 | 家庭列表、邀请码、主题、提醒开关 | 自己 / 家人 | 首次进入才打 |
| S105 | 从空间/标签/消息返回家庭页 | family `onShow` | 无 | 0 | 本页实例还在时家庭列表通常没变 | 无（家人改主题则看不到） | **已跳过重打**，注释写明 |

### 物资首页

每次 `onShow` 都会跑完整包，**不管是第一次进来、从详情返回，还是从后台回来**。

| ID | 触发 | 当前调用 | 约次数 | 可能已变 | 变更来源 |
|----|------|----------|--------|----------|----------|
| S201 | 首页出现 | `space.list`；若空则 `space.ensureDefault` 再 `space.list` | 1～3 | 空间增删改名 | 自己 / 家人 |
| S202 | 紧接 S201 | `item.search`（当前筛选空间） | 1 | 物资增删改、换空间 | 自己 / 家人 |
| S203 | 与 S202 并行 | `item.count`（全家总数，不受空间筛选） | 1 | 物资增删 | 自己 / 家人 |
| S204 | 紧接 S201 | `item.listExpiring`（`limit: 1`，只为横幅） | 1 | 物资过期日变化；**即使物资没改，过了零点文案也会变** | 自己 / 家人 / **时间** |
| S205 | S204 有临期物且缺位置名 | `space.listLocations` | 0～1 | 位置改名 | 自己 / 家人 |
| S206 | 首页点选另一个空间 | 只再打 `item.search` | 1 | 筛选条件变了，列表必须换 | 自己（筛选，不是写库） |

一次「回首页」常见合计：**4～6 次**。会话已缓存时仍是这些。

### 物资详情

`onLoad` 打一遍；之后每次 `onShow`（从编辑返回、从后台回来）再打一遍（silent）。

| ID | 触发 | 当前调用 | 约次数 | 可能已变 | 变更来源 |
|----|------|----------|--------|----------|----------|
| S301 | 进入 / 再次显示详情 | `item.get` | 1 | 该条物资字段 | 自己 / 家人 |
| S302 | 有 `spaceId` | **整表** `space.list`，只为取一个空间名 | 1 | 空间改名 | 自己 / 家人 |
| S303 | 有位置 | `space.listLocations` | 1 | 位置改名 / 删除 | 自己 / 家人 |
| S304 | 有标签 | `tag.list` | 1 | 标签改名 / 删除 | 自己 / 家人 |
| S305 | 最近操作 | `activity.list`（`itemId`, limit 10） | 1 | 该条操作日志 | 自己 / 家人 |

一次详情 **最多 5 次**。空间名/标签名与物资本体不是同一份数据。

### 新建 / 编辑物资

编辑页 `onShow` **不再读**（只绑主题）。读发生在 `onLoad` → `bootstrap`，以及改空间、新建位置。

| ID | 触发 | 当前调用 | 约次数 | 可能已变 | 变更来源 |
|----|------|----------|--------|----------|----------|
| S401 | 打开新建 | `tag.ensureDefaults` + `space.list`（空则 `ensureDefault`）+ `listLocations` | 3～4 | 空间/标签/位置选项 | 自己 / 家人 |
| S402 | 打开编辑 | S401 再加 `item.get` | 4～5 | 另加该条物资 | 自己 / 家人 |
| S403 | 表单里换空间 | `space.listLocations` | 1 | 新空间的位置列表 | 无（换筛选项） |
| S404 | 表单里新建位置成功 | `space.createLocation`（写）+ 再 `listLocations` | 1 写 + 1 读 | 位置列表刚被自己改 | 自己 |

`ensureDefaults` 走的是写能力云函数：库里已有默认标签时多半是读，但**每次进编辑/标签页都会调**。

### 空间 / 位置

| ID | 触发 | 当前调用 | 约次数 | 可能已变 | 变更来源 |
|----|------|----------|--------|----------|----------|
| S501 | 空间列表每次 `onShow` | `space.list`；空则 `ensureDefault` 再 `list` | 1～3 | 空间增删改名 | 自己 / 家人 |
| S502 | 空间详情 `onLoad` / 每次 `onShow` | `space.listItemsBySpace` + `listLocations` | 2 | 该空间物资、位置 | 自己 / 家人 |

### 标签 / 家庭消息

| ID | 触发 | 当前调用 | 约次数 | 可能已变 | 变更来源 |
|----|------|----------|--------|----------|----------|
| S601 | 标签页每次 `onShow` | `tag.ensureDefaults` | 1 | 标签增删改名；也可能触发种子写入 | 自己 / 家人 |
| S602 | 消息页每次 `onShow` | `activity.list`（limit 40，含昵称回填） | 1 | 物资操作日志 | 自己 / 家人 |

### 口袋（无站内入口）

| ID | 触发 | 当前调用 | 约次数 | 可能已变 | 变更来源 |
|----|------|----------|--------|----------|----------|
| S701 | 口袋页每次 `onShow` | `space.list` + **每个空间** `listItemsBySpace` | 1 + N | 全空间物资 | 自己 / 家人 |

N 个空间就是 N+1 次，是目前单页放大最明显的读。

## B. 本机写成功之后的读

这些是「自己刚改完，屏幕要跟上」。写本身必打云函数（不能靠缓存省），表里只记**写完后又打了哪些读**。

| ID | 触发 | 写 | 写完后的读 | 备注 |
|----|------|----|------------|------|
| S801 | 首页没有空间时自动补默认 | `space.ensureDefault` | 再 `space.list`（见 S201） | 读路径上的懒创建 |
| S802 | 保存新建/编辑物资 | `item.create` / `item.update` | 本页不读；`navigateBack` 后由**上一页 `onShow`** 全量再拉 | 上一页若是首页 → 回到 S201～S205；若是详情 → 回到 S301～S305 |
| S803 | 详情删除物资 | `item.remove` | 本页不读；返回上一页 `onShow` 全量再拉 | 同 S802 |
| S804 | 编辑页新建位置 | `space.createLocation` | `listLocations`（S404） | |
| S805 | 空间列表创建/改名/删除 | `space.create` / `update` / `remove` | 本页再 `load` → S501 | |
| S806 | 空间详情创建/改名/删除位置 | `createLocation` / `updateLocation` / `removeLocation` | 本页再 `load` → S502 | 删除位置会先本地去掉一行再全量拉 |
| S807 | 标签创建/改名/删除 | `tag.create` / `update` / `remove` | 本页再 `ensureDefaults` → S601 | |
| S808 | 家庭页创建/加入家庭 | `family.create` / `join` | 再 `getMyFamily` + `listMyFamilies` | |
| S809 | 切换家庭 | `family.switchFamily` | **本页用返回体，不再 list**；底下的首页/详情之后 `onShow` 仍会按 A 组全量拉 | 切家后旧家缓存必须作废（方案阶段再定） |
| S810 | 改主题 / 改家庭过期总开关 | `updateBackground` / `updateExpireReminder` | 本页用返回体，不重拉列表 | 主题在 `globalData`；其它页下次 `bindThemeToPage` 能吃到 |
| S811 | 编辑页打开「过期提醒」 | 可能 `family.recordSubscribeExpire` | 无后续读 | 订阅授权，不写 `activities` |
| S812 | 离开/解散家庭 | `family.leave` | 有下一家则用本地列表拼当前家；拼不出再 `load`（S104）；没有家则 `reLaunch` onboarding | |

物资 create / 有字段变更的 update / remove **成功后**云函数旁路写 `activities`。活动插入失败不回滚物资写（见 `collections.md`）。

## C. 数据可能已经变了，但当前没有对应的读

这些现在**不会**因为「变了」而打接口；只有用户再次触发 A/B 才可能看到新数据。盘场景时要算进去，否则缓存会把「看不见」变成「更长时间看不见」。

| ID | 发生了什么 | 哪类数据过期 | 当前会不会发现 | 有没有日志 |
|----|------------|--------------|----------------|------------|
| S901 | 家人在另一台设备增删改物资 | 列表、数量、临期、详情、消息、空间内物资 | 要等本机某页再次 `onShow` 盲拉 | **有** `activities`（create / 有变更的 update / remove） |
| S902 | 家人改了空间名 / 位置名 / 标签名 | 首页卡片上的地点和标签、详情上的名称、筛选名 | 同上，盲拉 | **无**。C 波规定非物资写不进消息 |
| S903 | 家人增删空间、位置、标签 | 选项列表、口袋 N+1、空间详情 | 同上 | **无** |
| S904 | 家人改了家庭主题 / 过期总开关 / 家庭名 | 氛围色、家庭页开关和标题 | 家庭页若已跳过 `load`（S105）则**本页看不到**；其它页主题靠 `globalData`，也可能旧 | **无** |
| S905 | 上海时区过了零点 | 临期横幅、详情保质期文案；物资本体没变 | 只有再次打 `listExpiring` 或本地重算日期才会变 | **无** |
| S906 | 物资写成功但 `activities` 插入失败 | 物资本体已变，日志水位仍旧 | 若以后用水位当「物资有没有变」，会**漏刷新** | 水位不可靠的边角 |
| S907 | 只改了个人过期订阅，没改物资字段 | `itemExpireSubs` | 详情/编辑靠 `item.get` 才带 `expireReminderEnabled` | **不写** activities（已文档化） |
| S908 | 定时器 `expireNotify` 发了订阅消息 | 推送，不是列表数据 | 客户端无读 | 与缓存无关 |
| S909 | 停留在某一页不离开，家人改了数据 | 当前页 `data` | **无实时**，不 `onShow` 就不读 | 同 S901～S903 |

## D. 组合路径（便于估额度，不是新场景）

原子场景叠在一次操作上的数量，方便对照「省的是哪一段」。

| 路径 | 叠哪些 | 约调用次数 |
|------|--------|------------|
| 冷启动已有家 → 首页 | S102 + S103缓存 + S201～S204 | **5～7** |
| 首页 → 详情 → 返回首页 | S301～S305 + 再 S201～S204 | **9～11**（不含进首页那次） |
| 详情 → 编辑 → 返回详情 | S401/S402 + 再 S301～S305 | **9～10** |
| 首页 ↔ 家庭页首次 | S104（2）+ 返回后再 S201～S204 | 家庭页 2，回首页再 4～6 |
| 家庭 → 标签 → 回家庭 | S601；家庭页 S105 不打 | 标签每次 show 1 次 |
| 切微信再回来（停在首页） | 再跑 S201～S204 | **4～6**，物资往往没变 |

## E. 按数据域对照（后面定方案用）

| 数据域 | 典型读 | 谁会改 | 改了有没有 `activities` | 主要出现在 |
|--------|--------|--------|-------------------------|------------|
| 当前家庭 / 会话 | `getMyFamily` | 切家、离家、主题、提醒开关、人数 | 无 | S101～S105、S808～S812 |
| 家庭列表 | `listMyFamilies` | 创建/加入/离开 | 无 | S104、S808 |
| 物资列表 / 计数 / 临期 | `search` / `count` / `listExpiring` / `listItemsBySpace` | 物资增删改；临期还跟日期走 | **有**（物资本体） | S202～S204、S502、S701 |
| 单条物资 | `item.get` | 该条增删改、订阅开关 | 字段变更有；订阅无 | S301、S402、S907 |
| 空间 | `space.list` | 空间 CRUD、ensureDefault | 无 | S201、S302、S401、S501 |
| 位置 | `listLocations` | 位置 CRUD | 无 | S205、S303、S403、S502 |
| 标签 | `tag.list` / `ensureDefaults` | 标签 CRUD、种子 | 无 | S304、S401、S601 |
| 操作日志 | `activity.list` | 物资写成功旁路 | 自身即日志 | S305、S602、S901、S906 |

已有缓存 / 跳过，仅供对照，不是方案：

- `globalData.family`：`ensureSession` 默认复用（S103）。
- 家庭页：已有 `data.family` 则 `onShow` 不重拉（S105）。
- 编辑页：`onShow` 不重拉（读只在 bootstrap / 换空间）。
