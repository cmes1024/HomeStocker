## 1. 项目概述

### 1.1 项目背景
家庭日常生活中，物资管理普遍存在以下痛点：
- 物资存放位置分散（冰箱、储物柜、阳台等），遗忘后重复采购
- 食品、药品等有保质期的物品过期浪费
- 多人共用家庭物资时信息不对称，缺乏统一管理入口
- 传统手动录入繁琐，用户操作意愿低

### 1.2 产品定位
一款以**家庭**为核心单位的轻量级物资管理微信小程序，帮助家庭成员协同管理家中各类物资，减少浪费、避免重复采购。

### 1.3 目标用户
- 家庭主妇/主夫：管理家庭日常食材、日用品
- 合租室友：共享公共物资信息
- 有老人/小孩的家庭：管理药品、保健品等特殊物资
- 小型团队/工作室：管理办公耗材、零食等共享物资

## 2. 核心功能

### 2.1 家庭管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 创建家庭 | 用户可创建多个家庭（如：自己家、父母家） | P0 |
| 加入家庭 | 通过邀请码/分享链接加入他人创建的家庭 | P0 |
| 切换家庭 | 在多个家庭间快速切换，数据隔离 | P0 |
| 常驻家庭切换栏 | 首页顶部常驻家庭切换组件，展示当前家庭名称，点击可下拉切换 | P0 |
| 家庭列表管理 | 家庭 Tab 展示全部家庭，支持查看当前家庭、切换家庭、新增家庭、编辑家庭、删除家庭 | P0 |
| 退出/解散家庭 | 成员可退出，创建者可解散家庭 | P1 |
| 家庭基础设置 | 家庭名称、头像等基本信息编辑 | P2 |
| 家庭提醒总开关 | 每个家庭可独立开启/关闭到期提醒，首页临期模块仅展示已开启提醒的家庭数据 | P1 |

### 2.2 角色与权限

| 角色 | 权限范围 |
|------|----------|
| 创建者（Owner） | 全部权限：管理成员、设置角色、增删改查所有物资、解散家庭 |
| 管理员（Admin） | 增删改查所有物资、查看成员列表、审批加入申请 |
| 普通成员（Member） | 查看和编辑所有物资（不可删除他人录入的物资）、查看成员列表 |
| 只读成员（Viewer） | 仅查看物资信息，不可编辑 |

### 2.3 物资管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 添加物资 | 录入物资名称、分类、数量、存放位置、保质期、过期提醒开关（默认关闭）、备注 | P0 |
| 物资列表 | 支持卡片与表格双模式展示；按分类/位置筛选、搜索，支持排序（到期时间、添加时间） | P0 |
| 物资详情 | 查看完整信息、操作历史、编辑记录 | P0 |
| 编辑物资 | 修改数量、位置、保质期、过期提醒开关等信息 | P0 |
| 删除物资 | 软删除，保留历史记录 | P1 |
| 快速操作 | 一键增加/减少库存数量 | P1 |
| 表格展示模式 | 列表页支持切换为紧凑表格视图，多列展示物资关键字段 | P1 |
| 过期提醒开关 | 添加/编辑物资时可设置是否对该物资开启到期提醒，默认关闭；仅已开启的物资触发提醒 | P0 |
| 批量操作 | 批量标记用完、批量修改位置 | P2 |

### 2.4 存放位置管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 预设位置 | 系统预置常见位置（冰箱冷藏、冰箱冷冻、厨房柜、阳台等） | P0 |
| 自定义位置 | 每个家庭可自定义存放位置 | P0 |
| 位置视图 | 按存放位置分组展示物资 | P1 |

### 2.5 保质期管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 到期提醒 | 仅对开启提醒开关的物资推送订阅消息；家庭可配提前天数（0/1/3/7/14 天，默认 3 天）与每日发送时分（默认 08:00），同时受家庭提醒总开关控制。微信一次性订阅每条只发一次，故只保留单档提前量 | P0 |
| 过期标记 | 自动标记过期物资，首页高亮展示 | P0 |
| 临期筛选 | 筛选即将到期的物资列表（含已开启/未开启提醒开关的全部临期物资） | P1 |
| 保质期日历 | 日历视图展示各物资到期时间分布 | P2 |
| 提醒开关管理 | 物资详情页可随时开启/关闭提醒，支持批量开关操作 | P1 |

### 2.6 分类管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 系统预设分类 | 食品饮料、生鲜果蔬、调味品、药品保健、日用品、母婴用品、宠物用品等 | P0 |
| 自定义分类 | 家庭可创建自定义物资分类 | P1 |
| 分类统计 | 按分类统计物资数量和临期/过期数量 | P2 |

### 2.7 AI 辅助录入

| 功能 | 描述 | 优先级 |
|------|------|--------|
| OCR 拍照录入 | 拍摄购物小票/包装条形码，自动识别商品信息并填充表单 | P0 |
| 语音录入 | 语音描述物资信息，AI 解析并自动填充 | P1 |
| 手动编辑确认 | AI 识别结果可手动修改，用户确认后才保存 | P0 |
| 批量识别 | 一张照片识别多个商品（如购物小票） | P1 |

### 2.8 采购管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 采购清单 | 手动添加待采购物品，支持勾选完成 | P1 |
| 智能建议 | 根据历史消耗和临期物资，自动推荐采购清单 | P2 |
| 消耗统计 | 记录物资消耗趋势，辅助采购决策 | P2 |

## 3. 用户流程

### 3.1 新用户引导
```
首次打开且未创建/加入任何家庭 → 微信授权登录 → 新用户引导页
  ├── 创建第一个家庭 → 设置家庭名称 → 进入首页（默认家庭）
  └── 加入已有家庭 → 输入邀请码 → 等待审核/直接加入 → 进入首页（默认家庭）

已存在家庭记录 → 直接进入首页
```

### 3.2 核心操作流程
```
首页（家庭维度信息直览）
  ├── 顶部家庭切换栏 → 作为多家庭主入口，点击进入家庭列表并切换当前家庭
  ├── 临期提醒模块 → 仅展示已开启提醒开关的家庭与物资数据
  ├── 添加物资 → 拍照/扫码/手动录入 → 设置过期提醒开关 → AI识别 → 确认信息 → 保存
  ├── 查看物资 → 卡片/表格双模式切换 → 筛选/搜索 → 物资详情 → 编辑/删除
  ├── 临期提醒 → 查看临期列表 → 处理物资
  └── 家庭 Tab → 家庭列表管理 → 切换 / 新增 / 编辑 / 删除家庭 → 家庭设置 → 成员管理 → 位置管理 → 分类管理 → 家庭提醒总开关
```

## 4. 非功能需求

### 4.1 性能要求
- 首页加载时间 ≤ 2 秒
- 列表分页加载，单页 ≤ 20 条
- OCR 识别响应时间 ≤ 3 秒
- 支持 50 人以内家庭成员规模

### 4.2 可用性
- 核心功能支持离线查看（缓存最近数据）
- 异常状态友好提示（网络断开、识别失败等）
- 关键操作二次确认（删除物资、解散家庭等）

### 4.3 数据安全
- 家庭数据严格隔离，不同家庭间数据不可见
- 敏感操作（解散家庭、移除成员）需双重确认
- 用户退出家庭后，其创建的物资保留在家庭中

### 4.4 兼容性
- iOS 微信 8.0+、Android 微信 8.0+
- 适配 iPhone SE 至 iPhone 15 Pro Max 各尺寸屏幕
- 基础库最低版本 2.20.0

## 6. 成功指标

- DAU 次月留存率 ≥ 30%
- 用户日均添加物资 ≥ 2 条
- OCR 识别准确率 ≥ 90%
- 过期物资占比（过期数 / 总物资数）较使用前下降 ≥ 40%
