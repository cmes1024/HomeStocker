# MVP + 空间/位置 验收清单

部署前：创建集合与索引（见 `collections.md`）、粘贴安全规则、上传云函数 `family` / `item` / `space`（云端安装依赖）。

## 闭环（原 MVP）

- [ ] 账号 A 创建家庭，获得 6 位邀请码
- [ ] 账号 B 用邀请码加入同一家庭
- [ ] A/B 均可对同一批物资增删改查（名称、数量、备注）
- [ ] 未加入家庭的账号看不到该家庭物资

## 空间 / 位置

- [ ] 首次添加物资无需先建空间，自动落在「仓库」
- [ ] 可创建自定义空间；编辑物资时可改所属空间与具体位置
- [ ] 新建位置：编辑页「新建位置」后可选
- [ ] 家庭页「逛空间」→ 空间列表 → 单空间页看到该空间物资及位置文案
- [ ] 全家物资清单仍可用；可按空间筛选（有空间时）
- [ ] 默认仓库可改名不可删（`DEFAULT_SPACE`）；删除其它空间时物品迁到默认仓库并清空位置；最后一个空间仍拒绝（`LAST_SPACE`）
- [ ] 解散家庭后 `spaces` / `locations` 一并清理

## 约束

- [ ] 客户端直写 `items` / `spaces` / `locations` 被安全规则拒绝
- [ ] 已有家庭仍可再创建；join 已加入的同一家庭返回 `ALREADY_IN_FAMILY`
- [ ] 家庭页可切换当前家庭；离开/解散后若还有其他家庭则切过去，否则回 onboarding
- [ ] 家庭背景：渐变 / 纯色 / 图片可设；标题为「家庭 {名称}」
- [ ] `memberships` / `items` / `spaces` 列表查询走索引（无「缺少索引」报错）

## 导航

- [ ] 产品入口含 onboarding / items / family / spaces（无 demo、chat）
- [ ] `chatProxy` 目录仍在，未挂产品导航

## A 波

- [ ] 清单点击进入物品详情；清单无长按删除
- [ ] 物品详情页可编辑、可删除，删除成功后返回全家清单
- [ ] 更换氛围图或改为渐变/纯色时，会尝试删除旧背景 fileID
- [ ] 解散家庭时会尝试删除背景图；普通成员退家当前保留家庭背景，避免误删仍在使用的外观
- [ ] 物品详情页与空间页走分包加载；主包体积下降在微信开发者工具中确认
- [ ] 氛围图上传前自动压缩（边长/质量受限）
- [ ] Workers 本波明确延期：当前无高价值纯计算热点，后续结合 B 波过期计算再接入
